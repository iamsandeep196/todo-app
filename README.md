# todo-app backend
A simple backend API for Todo Application built using Node.js,Express.js,MongoDB, and JWT Authentication.

## Features
- User Registration
- User Login
- Create Todos
- Get Loged-in User Todos
- Update Todos
- Delete Todos
- Forgot Password
- Reset Password
- Logout
- JWT Authentication
- Protected Routes
- MongoDB Integration

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- crypto
