# todo-app backend
A simple backend API for Todo Application built using Node.js,Express.js,MongoDB, and JWT Authentication.

## Features
- User Registration
- User Login
- JWT Authentication
- Create Todo
- Get Loged-in User Todos
- Update Todos
- Delete Todos
- Forgot Password
- Reset Password
- Logout
- Protected Routes
- MongoDB Integration

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- crypto
